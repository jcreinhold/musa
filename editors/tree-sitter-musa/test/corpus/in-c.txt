// Terry Riley's *In C* is fifty-three short figures. Each player repeats each
// figure as many times as they like, then moves on; the piece ends when the
// last player reaches the end. This file is that *form* — the figures below
// are written for musa rather than transcribed, because the 1964 work is not
// ours to copy — and it is here as a test of one thing: fifty-three decision
// sites in one piece, each of which must survive an edit to any of the others.
//
// Each figure is `repeat n to m { … }`, so its path is `figure_seven ▸ #0` —
// named by the fragment it sits in, not by its position in the voice. Adding a
// fifty-fourth figure therefore re-rolls nothing
// (`docs/kernel/11-realization.md`).
//
//     musa check examples/in-c.musa --seed 42
//
// Two departures from the original, both deliberate and both named in prompt
// 68's Stop list. The players do not enter when they like: musa compiles one
// plausible reading rather than a real-time coordination between performers.
// And every figure fills a measure exactly, so the barlines stay meaningful;
// Riley's do not, which is what unmeasured passages are for.
