// Text above U+007F, in every place a piece can carry it — the title, a
// section name, a phrase name, and these comments.
//
// It is here because the two sides of the desktop app measure the source
// differently: Rust counts bytes, JavaScript and CodeMirror count UTF-16
// code units, and the two agree only while the text is ASCII. The em dash on
// the line above is three bytes and one code unit; the flat sign below is
// three and one; the treble clef is four and two. Every span the interface
// receives from a piece like this one is wrong by the accumulated difference
// unless the shell restates it — see docs/rules/desktop/03-interaction.md §7.
//
// Nothing here is about notation. The notes are the plainest possible, so
// that when a linking or highlighting test fails it is the measure that is
// wrong and not the music.
