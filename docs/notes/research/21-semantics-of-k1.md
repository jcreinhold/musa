# Semantics of K₁

**Status: fixed semantic draft for review; governs nothing.** This note gives Candidate K₁ from
[20](20-candidate-staged-algebras.md) enough denotational and operational content to be falsifiable. “Implementation can
decide” is not a semantic clause.

The semantics has two levels:

- source evaluation is total, finite, and exact;
- process execution is causal, potentially unbounded, and physical.

The prepared render plan is the boundary between them. A signal is not forced into the source value universe.

---

## 1. Static environments and judgments

A static environment `Δ` contains:

- nominal identities and kinds for abstract types, clocks, and rates;
- rank-1 type parameters;
- normalized port-row declarations;
- quantifier-free linear natural constraints already entailed by the surrounding signature.

A value environment `Γ` contains immutable term variables. The principal judgments are:

```text
⊢ Δ ok                         static environment is well formed
Δ ⊢ A : κ                      type or index has kind κ
Δ ⊨ φ                          linear natural constraint is valid
Δ ; Γ ⊢ e : A                  term typing
Δ ; Γ ⊢ e ⇓ v : A              terminating source evaluation
⊢ p : Process k I O causal     process description is port-safe and causal
P ⊢ (σ,ι) ↦ (σ',ο)             one process tick
```

`Data <: Type`. Products, sums, finite vectors, strictly positive algebraic data, timelines, warps, and process
descriptions preserve `Data`; arrows do not.

```text
Δ ⊢ A : Data    Δ ⊢ c : Clock
────────────────────────────── Timeline-Form
Δ ⊢ Timeline c A : Data

Δ ⊢ k : Tick    Δ ⊢ I : Ports    Δ ⊢ O : Ports
──────────────────────────────────────────────── Process-Form
Δ ⊢ Process k I O : Data
```

A `Data` implementation owes a canonical finite byte encoding `enc_A`. The checker admits a nominal abstract data type
only when its defining structure supplies an encoder whose laws are tested at its ownership boundary:

1. `enc_A` is total and deterministic;
2. `enc_A(x)=enc_A(y)` iff the type's declared semantic equality identifies `x` and `y`;
3. the encoder contains no address, host-dependent iteration order, or unversioned float representation.

This is a semantic capability, not ad-hoc user overloading. Clients cannot choose a second equality for the same nominal
type.

## 2. Type conversion and inference boundary

Write `A ≡ B` for definitional type equality. It is the least congruence generated by:

- α-equivalence of bound static variables;
- nominal identity of abstract types, clocks, and named rates;
- evaluation of closed natural arithmetic;
- equality entailed in Presburger arithmetic by `Δ`;
- normalization of port rows by their distinct labels; and
- structural congruence of products, sums, vectors, timelines, warps, processes, and arrows.

There is no reduction of value terms during type conversion. In particular, timeline extents, pitch collections,
metrical plans, and user predicates never enter `≡`.

**Inference boundary.** K₁ infers local instantiations of rank-1 parameters from direct function arguments and solves
the resulting first-order equality constraints. Lambda parameters, exported definitions, structure members, empty
collections, and ambiguous numeric literals require annotations. The checker never guesses a clock conversion or a
domain translation.

This is not full dependent inference. It is elaboration of explicit types plus first-order unification and a small
arithmetic solver.

## 3. Denotation of the total value fragment

Fix a model environment `ρ` which assigns:

- a set `⟦X⟧ρ` to each abstract type `X : Type`;
- a set with decidable equality and canonical encoding to each `X : Data`;
- a distinct tag to each clock and rate;
- total functions to primitive operations satisfying their signatures.

The ordinary types have their standard set interpretation:

```text
⟦1⟧             = {⋆}
⟦Bool⟧          = {false,true}
⟦Nat⟧           = ℕ
⟦Rat⟧           = ℚ
⟦A × B⟧         = ⟦A⟧ × ⟦B⟧
⟦A + B⟧         = ⟦A⟧ ⊎ ⟦B⟧
⟦A → B⟧         = total functions ⟦A⟧ → ⟦B⟧ definable by the calculus
⟦Vec n A⟧       = n-tuples over ⟦A⟧
```

A strictly positive data declaration denotes its initial algebra. Its fold is the unique homomorphism from that initial
algebra to the supplied carrier. This is the only recursion in source terms.

An abstract type's meaning is not recovered by looking through its module. Sealing is semantically existential: a
structure supplies a witness representation and its operations, while clients reason only from the signature.

## 4. Timeline denotation

Let `Q = ℚ≥0`. A timeline over clock `c` and data payload `A` denotes

```text
T_c(A) = { (d,E) |
             d ∈ Q,
             E is a finite multiset of (s,e,a),
             0 ≤ s ≤ e ≤ d,
             a ∈ ⟦A⟧ }
```

The clock is a nominal tag. It prevents unmediated composition of distinct coordinates but does not change the set
above.

```text
⟦empty(d)⟧        = (d,∅)
⟦place(d,s,e,a)⟧ = (d,{(s,e,a)})       when 0 ≤ s ≤ e ≤ d
```

An invalid `place` produces `Err(BoundsError)` before a timeline exists. For `M=(d,E)` and `N=(e,F)`:

```text
M ; N = (d+e, E ⊎ τ_d(F))
        where τ_d(s,t,a) = (d+s,d+t,a)

M ⊕ N = (max(d,e), E ⊎ F)

T_c(f)(d,E) = (d,{(s,e,f(a)) | (s,e,a)∈E})
```

These are the existing Musa definitions. In particular, overlay has no equal-extent premise and inserts no payload.

### 4.1 Equality and normal form

The normal form of `(d,E)` is `d` in reduced rational form followed by the occurrence multiset sorted by

```text
(start, end, enc_A(payload))
```

with multiplicity retained. Timeline semantic equality `M ≡T N` is byte equality of these normal forms. This equality
forgets construction order and sharing but not extent, multiplicity, spans, or payload distinctions.

### 4.2 Algebraic laws

The definitions give:

- `;` is associative with unit `(0,∅)`;
- `⊕` is associative and commutative;
- at each fixed extent `d`, `(d,∅)` is the overlay unit;
- payload map is functorial and preserves `;` and `⊕`;
- synchronized interchange holds exactly under the current extent premises;
- neither distributivity nor a generic timeline `join` follows.

These are not type-theoretic axioms. They are propositions about the concrete denotation.

## 5. Clock-warp denotation

The first admitted `Warp c d` is a continuous, strictly increasing, piecewise-affine function

```text
w : Q → Q
```

with `w(0)=0`, finitely many rational breakpoints on every represented finite domain, and positive rational slopes. The
value stores a finite domain endpoint together with its segments; application outside that endpoint is an error unless
the final segment is explicitly marked extensible.

For `M=(d,E)` within the warp's domain:

```text
W_w(M) = (w(d), {(w(s),w(e),a) | (s,e,a)∈E})
```

Strict monotonicity preserves well-formed spans and their order. Define:

```text
id_c(t)          = t
(v ∘ w)(t)       = v(w(t))
tail(w,d)(t)     = w(d+t) - w(d)
```

`tail(w,d)` is again continuous, strictly increasing, piecewise affine, and sends zero to zero.

### 5.1 Laws

```text
W_id(M)                    = M                                      W1
W_v(W_w(M))                = W_(v∘w)(M)                             W2
W_w(M ⊕ N)                 = W_w(M) ⊕ W_w(N)                        W3
W_w(M ; N)                 = W_w(M) ; W_tail(w,extent(M))(N)        W4
W_w(T_c(f)(M))             = T_d(f)(W_w(M))                         W5
```

W3 uses monotonicity: `w(max(d,e)) = max(w(d),w(e))`. W4 is the important non-law made precise. A non-additive tempo or
groove warp cannot be mapped independently over both operands using the same origin. The second operand must receive the
rebased tail of the global warp.

### 5.2 Fermatas and discontinuities

A jump discontinuity would insert physical time at a logical point, but the function alone cannot say whether the
inserted interval belongs to a preceding occurrence, a following occurrence, a conductor gesture, or silence. Choosing
one globally would force a musical convention into the clock algebra.

K₁ therefore does **not** put discontinuous holds in the primitive warp. A performance theory resolves a fermata into a
finite performed-time timeline and a continuous warp after inspecting the marked occurrence and the performance profile.
This costs a real operation and is not erased. If a concrete repertoire requires a genuinely point-attached hold
independent of occurrences, it must first supply the missing boundary semantics; then a separate `JumpWarp` may be
considered.

### 5.3 Approximation at frames

`Seconds` remains an exact rational clock in finite plans. Conversion to `Frames r` takes an explicit rounding policy:

```text
q_(r,p)(t) = p(r·t) ∈ ℕ
```

The result contains the chosen integer endpoints and an error report `q(t)/r - t`. This conversion is monotone only for
appropriate rounding and collision policy; it is not part of definitional equality and does not pretend to preserve
positive durations smaller than one frame.

## 6. Process denotation

Fix a discrete tick clock `k`. Each port row `I` denotes a finite product of per-tick values. The audio interpretation
uses `k = Frames r`; an interaction protocol may use a different nominal tick and event payloads.

```text
⟦Audio n⟧frame   = Float^n
⟦Control A⟧frame = ⟦A⟧
⟦Events E⟧frame  = List ⟦E⟧
⟦I ⊗ J⟧frame     = ⟦I⟧frame × ⟦J⟧frame
```

A history over `I` is a function `x : ℕ → ⟦I⟧frame`. Write `x =_n y` when `x(k)=y(k)` for every `k≤n`.

A function `F : Hist(I) → Hist(O)` is **causal** when

```text
x =_n y  ⇒  F(x) =_n F(y)
```

for every `n`. It is **strictly causal in feedback port X** when the X-output at frame `n+1` depends only on X-input
through frame `n`.

The extensional denotation of `Process k I O` is a causal function `Hist(I) → Hist(O)`, together with an intensional
finite state-machine presentation used for execution. A primitive supplies:

```text
S_p          a finite runtime-state layout
init_p       an initial state fixed by explicit parameters and seed
step_p       S_p × ⟦I⟧frame → S_p × ⟦O⟧frame
```

Its stream function is obtained by primitive recursion on frame number. Stateful does not mean nondeterministic: every
source of variation, including a noise seed, is an explicit input to `init_p`.

### 6.1 Serial, parallel, and symmetry

```text
⟦wire⟧             = identity history function
⟦serial(p,q)⟧      = ⟦q⟧ ∘ ⟦p⟧
⟦parallel(p,q)⟧    = ⟦p⟧ × ⟦q⟧ pointwise
⟦permute(π)⟧       = the induced product permutation
```

These form a symmetric monoidal category of causal processes. Unlike timeline overlay, process parallel therefore obeys
unrestricted interchange.

### 6.2 Guarded feedback

Suppose `p : Process k (I⊗X) (O⊗X)` is strictly causal in `X`. Define `feedback₁(p)` tick by tick:

```text
x₀      = initial_X
(oₙ,xₙ₊₁) = p(iₙ,xₙ)
```

The recursion is well founded because frame `n` never asks for `xₙ₊₁` to compute itself. A graph-validation witness
`GuardedProcess` records that every path from feedback input to feedback output crosses a primitive with at least one
frame of stateful delay. Instantaneous cycles have no such derivation and are rejected.

This matches the existing studio rule at the level “only a cycle through `Delay` is admitted,” but not yet at the exact
tick semantics. **Verified in `crates/musa-audio/src/plan.rs`:** the current scheduler cuts edges *into* a delay node on
a cycle and lets that node read the upstream buffer from the end of the previous **block**. That is strictly causal by
more than one frame, but it is not the one-frame recurrence written above. A K₁ implementation must choose and specify
one of two honest models: make the process tick a render block and treat the delay's internal sample loop separately, or
compile guarded feedback to a finer frame schedule. It may not claim byte-identical operational correspondence while
retaining the current block-latency scheduler silently.

An author writes a delay processor, not a proof. The compiler constructs or fails to construct the guard witness.

## 7. Source operational semantics

Source evaluation is environment-based, deterministic, left-to-right call by value. Representative rules are:

```text
ρ(x)=v
──────────── Eval-Var
ρ ⊢ x ⇓ v

ρ ⊢ e₁ ⇓ ⟨fn x.e,ρ₀⟩    ρ ⊢ e₂ ⇓ v₂    ρ₀[x↦v₂] ⊢ e ⇓ v
────────────────────────────────────────────────────────── Eval-App
ρ ⊢ e₁(e₂) ⇓ v

ρ ⊢ e₁ ⇓ v₁    ρ[x↦v₁] ⊢ e₂ ⇓ v₂
──────────────────────────────────── Eval-Let
ρ ⊢ let x=e₁ in e₂ ⇓ v₂
```

Data folds evaluate by structural recursion on an already evaluated finite constructor value. Timeline, warp, and
process combinators build or normalize finite descriptions; none runs a signal.

Evaluation errors are values of `Result` only. Resource exhaustion is a deterministic compiler acceptance judgment
outside the term reduction, as in the current Musa core; it does not publish a partial value.

### 7.1 Erasure

Elaboration produces a monomorphic core by erasing:

- rank-1 type abstraction and application;
- kind arguments;
- solved natural constraints;
- module sealing witnesses;
- port-row equality and guard derivations after graph validation.

The graph, its delay nodes, static parameter values, timeline spans, warps, seeds, and all domain data remain. Erasure
therefore changes no source denotation.

## 8. Timeline and process normalization

### 8.1 Timeline

Timeline operations may be retained as sharing terms during elaboration. Evaluation flattens them into the canonical
normal form of §4.1. The existing kernel term calculus and law suite already implement this stage.

### 8.2 Warp

A warp normal form:

1. reduces all rational endpoints and slopes;
2. rejects nonpositive slopes or unordered breakpoints;
3. merges adjacent collinear segments;
4. removes a redundant final breakpoint; and
5. records its finite domain and extension policy.

Equality is byte equality of this normal form. Extension policy is semantic and cannot be omitted from the key.

### 8.3 Process

A process normal form is a typed, finite directed graph with:

- canonical port labels and node order;
- primitive kind and canonical parameter bytes at each node;
- explicit permutations and adapters only where semantically necessary;
- every external port connected exactly as its primitive contract requires;
- each instantaneous strongly connected component rejected;
- each guarded feedback component cut at its designated state edge for scheduling.

Structural diagram equality and DSP denotational equality are different. Normalization quotients only diagrammatic
associativity, units, symmetry, and canonical naming. It does not attempt to decide equality of arbitrary filters or
causal functions.

## 9. Preparation and the actual R1 theorem

Preparation is split into a canonical value and an allocated executable:

```text
prepare_spec : NormalTimeline Gesture
            × CanonicalBindings
            × NormalProcess r I O
            × Seed
            × PrepareOptions
            → Result PreparedSpec PrepareError

allocate : PreparedSpec × DeviceOptions → Result RuntimePlan DeviceError
```

`PreparedSpec` contains exact scheduled facts as far as possible and records every float/quantization conversion with
its policy. `RuntimePlan` owns buffers and host resources and has no source-language equality.

Let `nf_T` and `nf_P` be the canonical normalizers. Define the public operation by

```text
prepare(M,B,P,s,o) = prepare_spec(nf_T(M), canon(B), nf_P(P), s, o)
```

where every argument is explicit and every function on the right is deterministic.

**Proposition R1-K₁ — quotient invariance of preparation.** If `M ≡T N`, `B` has the same canonical value, `P` has the
same process normal form, and `s,o` are equal, then

```text
prepare(M,B,P,s,o) = prepare(N,B,P,s,o).
```

*Argument.* `M ≡T N` means `nf_T(M)=nf_T(N)` by definition. Substitution of equal arguments into the deterministic
function `prepare_spec` gives equal results. ∎

This proposition is deliberately weaker and more accurate than “structural recursion proves R1.” Structural recursion
proves termination of `prepare_spec`; the factorization through canonical normal form proves quotient invariance.

**Corollary R1-render.** If `allocate` and every processor primitive are deterministic functions of the prepared spec,
device options, and explicit seed, and if the runtime receives the same event/input history, the output sample histories
are equal frame by frame.

This corollary does not follow from source typing. It is a contract of the audio implementation and must be tested.

## 10. Coherence among views

K₁ does not promise a single commuting polygon for every realization. Each named bridge states its own coherence law.
Examples:

```text
interpret(map_notation(f,M), profile)
    ≈ map_gesture(interpret_f(f,profile), interpret(M,profile))

warp(w, over(M,N))
    = over(warp(w,M), warp(w,N))

compile(serial(p,q))
    ≈ compose_runtime(compile(p),compile(q))
```

The first law is theory-specific and may produce evidence of approximation; the latter two are generic. This is what
“coherent” should mean in Musa: an explicit family of typed laws at actual bridges, not an assertion that notation and
sound are the same object.

## 11. What these semantics rule out

1. A chord cannot “fall out” merely from `over`; chord classification needs a theory-defined function on simultaneous or
   near-simultaneous material.
2. A key, rāga, or maqām cannot be an index required by `Timeline`; each is optional domain data with its own laws.
3. `Warp` cannot represent every temporal practice by fiat. Interactive timing is a process, and a fermata requires an
   interpretation decision before it becomes a continuous warp.
4. A processor graph cannot be evaluated by source normalization. Only its finite description can.
5. R1 does not follow from CBPV, the function type alone, or recursion. It follows from canonical factorization plus
   deterministic preparation, and frame equality additionally depends on the runtime.
6. Analysis cannot be definitional equality unless a specific theory intentionally declares and justifies that quotient.
