# Candidate S — native worlds are compositional process theories

**Status: candidate component. Governs nothing.** [11](11-candidate-relational-presentation.md) can connect arbitrary
typed things, but it does not make musical or audio constructions natural. This note adds exactly one idea: inside each
native world, things compose in series and in parallel.

**One-line claim.** A notation, performance, analysis, or audio world should be presented as a symmetric monoidal
category generated by its native atoms. Sequential composition is categorical composition; independent parallel
composition is tensor. A realization which preserves those operations is a symmetric monoidal functor.

This is deliberately only an internal theory of one world. [13](13-candidate-modules.md) asks how unlike worlds should
be linked without identification.

---

## 1. Phenomena and consumers

The candidate must support four concrete downstream constructions without naming them as kernel primitives.

1. Several tones sounding together should be built from the same parallel constructor as several independent voices.
2. A chain and a parallel bank of audio processors should be ordinary term formation, not bespoke graph algorithms.
3. Reassociation and exchange of independent components should not change denotation.
4. An interpretation of generators should extend compositionally to every diagram.

The boundary examples are equally important.

- Order may matter inside a melody or a processor chain, so the parallel operation must not replace sequential
  composition.
- Parallel components may interact through a later mixer or acoustic model, so tensor means independent juxtaposition,
  not “their physical effects never interact.”
- A key, a tempo map, and a notation-to-audio correspondence are not supplied merely by having a tensor product.

The local categorical reference defines a monoidal category as a category with an associative tensor and unit, with
coherence data, and records Mac Lane's strictification theorem
([Higher Topos Theory, Appendix A.1.3](../../../../papers/category-theory/higher-topos-theory/37-a-1-category-theory.md)).
The strict syntax below uses that coherence result as a presentation convenience, not as an equality claim about every
semantic model.

## 2. Candidate definition

Fix a typed generating signature `Σ`. It contains object generators—such as signal port shapes or passage interfaces—and
arrow generators—such as a primitive processor or a note-producing action—with declared source and target object
expressions.

**Definition 12.1 (process world).** The process world freely generated by `Σ` is a strict symmetric monoidal category
`F⊗(Σ)` whose objects and maps are generated by

```text
A, B ::= I | a | A ⊗ B

f, g ::= id_A | primitive | g ∘ f | f ⊗ g | swap_(A,B)
```

subject only to the category, strict monoidal, symmetry, and interchange laws. Domain equations are not included until
they are declared separately.

The important equations are structural:

```text
h ∘ (g ∘ f) = (h ∘ g) ∘ f
id ∘ f = f = f ∘ id
(g₁ ⊗ g₂) ∘ (f₁ ⊗ f₂) = (g₁ ∘ f₁) ⊗ (g₂ ∘ f₂)
swap_(B,A) ∘ swap_(A,B) = id_(A⊗B)
```

The typing premises of interchange already require the two serial paths to have matching interfaces. No temporal extent
premise is inserted into the generic law.

### 2.1 States and parallel configurations

A state of an object `A` is a map `x : I → A` from the tensor unit. If `x : I → A` and `y : I → B`, their tensor is

```text
x ⊗ y : I ⊗ I → A ⊗ B,
```

and strictness identifies the source `I ⊗ I` with `I` in the syntax. Thus a finite parallel configuration is derived by
repeated tensoring of states.

**Proposition 12.2 (parallel states are derived).** In any monoidal category, a finite family of states `xᵢ : I → Aᵢ`
determines a state `⊗ᵢ xᵢ : I → ⊗ᵢ Aᵢ`, uniquely up to the associativity and unit coherence isomorphisms. A permutation
of the family changes this state by the corresponding symmetry isomorphism.

**Proof.** For two states, tensoring gives `x₁ ⊗ x₂ : I ⊗ I → A₁ ⊗ A₂`; compose its source with the inverse unit
isomorphism `I ≅ I ⊗ I`. Iterate this construction for a finite family. Mac Lane coherence makes any two choices of
parenthesization and unit isomorphisms equal as canonical maps. A permutation is implemented by the symmetry maps, and
the symmetric coherence theorem makes the resulting canonical symmetry independent of its decomposition into adjacent
swaps. ∎

**JUDGED.** When the `xᵢ` are pitched tone states in one temporal context, this is the structural construction
underlying a chord or sonority. It does not decide pitch spelling, voicing identity, doubling semantics, or whether a
culture calls the result a chord. Those are structures on the resulting parallel configuration.

### 2.2 Processor graphs

If `filter : Audio → Audio` and `gain : Audio → Audio`, then `gain ∘ filter` is a serial chain. If
`left : Audio → Audio` and `right : Audio → Audio`, then `left ⊗ right` is a parallel bank. A mixer is an ordinary
domain generator such as `mix : Audio ⊗ Audio → Audio`; it is not confused with the structural tensor.

The distinction matters. Tensor builds two wires. `mix` performs an audio operation on them. Treating tensor itself as
summation would force an audio-specific algebra on every world.

### 2.3 Realizations as models

**Definition 12.3 (compositional realization).** Let `C` be a symmetric monoidal semantic category. An interpretation of
`Σ` in `C` assigns semantic objects and maps to every generator with the declared types. A compositional realization is
the induced strong symmetric monoidal functor `⟦-⟧ : F⊗(Σ) → C`.

**Design obligation 12.4 (free extension).** Every typed interpretation of the generators of `Σ` in `C` extends to a
strong symmetric monoidal functor from `F⊗(Σ)` to `C`, unique up to a unique monoidal natural isomorphism whose
components on generators are identities.

This is the universal property that the implementation of the free syntax must satisfy. It is not proved merely by
calling the syntax free: a construction must still define the functor recursively on diagrams, verify all structural
equations, and establish the stated uniqueness comparison.

## 3. Type system and normal form

The term judgments are small:

```text
Σ ⊢ A object
Σ ⊢ f : A → B
```

The only generic formation rules are identity, composition, tensor, and symmetry. The concrete syntax can elaborate to a
typed directed acyclic string diagram:

- boundary ports carry object types;
- boxes carry generator labels;
- wires connect equal types;
- serial composition glues output and input boundaries;
- tensor takes disjoint union;
- symmetry rewires boundary order.

Structural normalization erases identity boxes, flattens serial and parallel syntax, and canonicalizes wire and box
identifiers. Equality in the free symmetric monoidal theory is graph isomorphism preserving typed boundary order and box
labels. Domain-specific equations require their own oriented, terminating rewrite system or explicit proof; they do not
become type conversion by proximity.

This normal form is close to [11](11-candidate-relational-presentation.md)'s typed hypergraph. The difference is
substantive: ports now have direction, deterministic boxes have a compositional map structure, and tensor is not merely
logical conjunction.

## 4. Denotational and operational readings

The denotational semantics is any strong symmetric monoidal functor out of the free world.

- In an audio model, objects are signal interfaces, maps are causal processors, tensor is parallel interface, and
  composition connects processors.
- In a notation model, objects may be engraving interfaces, maps layout or notation transformations, and tensor
  independent juxtaposition.
- In a finite musical-process model, maps can be passages with input and output boundary states, composition succession,
  and tensor independent voices.

Operational execution chooses a model whose maps have implementations. A typed diagram is scheduled in dependency order.
Feedback is absent from this candidate; adding arbitrary trace would create noncausal loops. A later audio theory may
admit a guarded trace or explicit delay generator and prove productivity there.

## 5. Emergence audit

| Intended concept | Does it fall out? | Reason |
| --- | --- | --- |
| Serial processor chain | **Yes** | categorical composition |
| Parallel processor bank | **Yes** | tensor |
| Mixer | **No, correctly** | it is a native audio map, not generic wiring |
| Parallel tones / chord carrier | **Yes, partly** | tensor of states; musical classification remains domain structure |
| Realization functor | **Yes, when functional and structure-preserving** | model of free monoidal syntax |
| Key / scale frame | **No** | no context or group action has been defined |
| Rubato / tempo relation | **No** | no temporal base or clock correspondence has been defined |
| Notation–audio ambiguity | **No** | an ordinary functor is too functional for many realizations |
| Unequal voice activity | **Unsettled** | tensor says parallel, not how temporal support is represented |
| Feedback | **No** | requires guarded trace or a causal fixed-point theory |

**Verdict.** Candidate S finds the internal algebra that Candidate R lacks. It is necessary for concepts to be
constructed rather than listed, but it is not sufficient. In particular, forcing every realization to be a functor would
repeat the identification error at the level of maps: many written objects admit several performances and sounds, and
many observations admit several analyses.

The next candidate keeps functors but makes them the special, functional case of a more general link.
