## 1. Temporal identity

For payload type `A`, its owner supplies a total deterministic key `key_A : A→ByteString`. The equality admitted to the
temporal kernel is:

```text
a ≈_A b  iff  key_A(a)=key_A(b).
```

The owner must document this quotient. If it claims another equality first, soundness and completeness of `key_A` for
that equality are admission obligations.

For a normalized timeline `M`, define:

```text
Sem_A(M) =
  (extent(M), sort [(start(o),end(o),key_A(payload(o))) | o∈occurrences(M)]).

M ≡_T N  iff  Sem_A(M)=Sem_A(N).
```

Multiplicity is retained. `encode_sem` is the versioned, domain-separated, uniquely decodable encoding from
[40 §3](40-canonical-framing-bug.md): canonical exact rationals, an occurrence count, and a byte length before every
payload key. Human display and interchange text are not definitions of `≡_T`.

### Theorem T2.2 — exact temporal comparison and hash agreement

Every closed checked K₃ᵀ term evaluates to exactly one finite normalized timeline. Structured comparison of `Sem_A`
decides `≡_T`. Moreover,

```text
M ≡_T N  iff  encode_sem(M)=encode_sem(N),
M ≡_T N  implies  h(M)=h(N),
```

where `h=FNV1a128∘encode_sem`. The converse of the second implication is not a theorem.

*Proof.* Evaluation and normalization are the governing structural T1–T4 proof. Decidability is Lemma F1 of [40]. The
encoding equivalence is Lemma F2. Hash agreement applies one deterministic function to equal framed bytes. No function
from infinitely many timeline forms to 128-bit values is injective. ∎

### Cache corollary C1.2

At a fixed implementation and semantic-schema version, a cache is correct when insertion stores the complete structured
arguments (or their injective framed encodings) and the result actually obtained by the deterministic operation. A
digest may select candidate entries. A hit is returned only after exact argument confirmation. This does not add lineage
equality or a content-only rendering law to R1.

## 2. Qualified anchors and primitive hops

Fix a finite artifact registry `ᶜ`. Every presentation `P∈ᶜ` has:

```text
id(P)       : PresentationId
Anchors(P)  : finite set AnchorId
root(P)     : AnchorId in Anchors(P)
Sites(P)    : finite subset of Anchors(P).
```

`Sites(P)` contains explicit rule/default/generation sites. A qualified anchor is `(id(P),a)` with `a∈Anchors(P)`.
Presentation ids and anchor ids have canonical encodings. The registry is immutable for the derivation being checked.

A primitive hop is:

```text
Hop = {
  from     : QualifiedAnchor,
  to       : QualifiedAnchor,
  pass     : PassId,
  role     : Preserved | Split | Merged | Generated
           | Approximated | Selected,
  evidence : CanonicalEvidence,
  region   : Option RegionMap
}.
```

It is well formed when:

1. both qualified anchors resolve in `ᶜ`;
2. `pass` names a declared pass from the source presentation kind to the target presentation kind;
3. its region, when present, lies inside both anchor regions;
4. a `Generated` hop's `from` is `root(P)` or belongs to `Sites(P)` in the hop's **own source presentation**; and
5. role-specific evidence is accepted by the pass owner.

The generated condition is local to the primitive hop. It is never reinterpreted against the outer endpoint of a later
composite.

## 3. Paths retain their witnesses

A path is stored as:

```text
Path = {
  vertices : NonEmpty List QualifiedAnchor,
  hops     : List Hop
}.
```

It is well formed when `length(vertices)=length(hops)+1`, every hop is well formed, and hop `i` has exactly
`from=vertices[i]` and `to=vertices[i+1]`. Its source and target are its first and last vertices. A reflexive path at
`a` is `([a],[])`.

If `p` ends where `q` begins, define path concatenation `q⋆p` by concatenating their vertex lists while dropping one
copy of the shared vertex, and concatenating their hop lists. No intermediate presentation, anchor, pass, role, or
evidence is summarized away.

### Lemma L0 — path closure

If `p` and `q` are well-formed paths and the target of `p` equals the source of `q`, then `q⋆p` is a well-formed path.

*Proof.* Dropping the duplicated joining vertex makes the new vertex count
`(|V_p|+|V_q|-1)=(|H_p|+1)+(|H_q|+1)-1=|H_p|+|H_q|+1`. Old hop/vertex adjacency is unchanged inside each operand, and
the last hop of `p` and first hop of `q` retain the shared qualified anchor at their boundary. Every hop retains its
original formation derivation. In particular, a generated hop retains the exact root or site anchor in its own source
presentation. ∎

### Lemma L0.1 — path associativity and units

Concatenation is associative, and the reflexive path at an endpoint is a two-sided unit.

*Proof.* Both associations produce the same vertex sequence with the two shared boundary duplicates removed and the same
hop sequence in the same order. List concatenation is associative. A one-vertex, zero-hop path contributes no new vertex
after boundary deduplication and no hop. ∎

## 4. Set-valued lineage

A lineage `L:S→T` is a finite canonical set of well-formed paths whose first vertex belongs to `S` and last vertex
belongs to `T`, such that every anchor of `T` is the target of at least one path. Full path data determines set
equality; stable derivation ids belong in evidence when two otherwise equal derivations must remain distinct.

Composition is:

```text
M∘L = { q⋆p | p∈L, q∈M, target(p)=source(q) }.
```

Identity on `S` is `{([a],[]) | a∈Anchors(S)}`.

### Theorem L1.2 — path lineages form a category

For a fixed artifact registry, presentations and target-total finite path lineages form a category.

*Proof.* Lemma L0 makes every composite member a well-formed path with the required outer presentations. For target
coverage, choose a path `q∈M` ending at an arbitrary anchor `u` of `U`. Its source is some anchor `t` of `T`. Coverage
of `L` supplies a path `p` ending at `t`; hence `q⋆p` is in the composite and ends at `u`. Finiteness follows from a
finite subset of the finite Cartesian product. Associativity follows pointwise from Lemma L0.1, and exact set
construction removes the same duplicates in either association. The displayed reflexive set is finite, target-total,
well formed, and is a two-sided unit by Lemma L0.1. ∎

### Corollary L2.2 — generated provenance survives composition

Every generated hop in a composite lineage still names and can validate the root or site anchor which justified it in
its source presentation.

*Proof.* Composition concatenates paths and never rewrites their primitive hops or intermediate vertices. Apply hop
formation condition 4 to the retained hop. ∎

This is deliberately a path category, not a claim that every representation is isomorphic or that derivation is
reversible. Reverse lookup indexes the finite outer and intermediate vertices; it does not invert a lossy pass.
