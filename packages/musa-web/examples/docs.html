Notes, bars, and ties

A note is one word

A pitch, an octave, a duration: c4/4.

piece "one-note" { tempo 1/4 = 60; meter 1/4; score { part piano { voice line { | c4/4 } } } }

The bar is the line

Bars that disagree with their meter are caught, not engraved:

piece "Over" { tempo quarter = 96; meter 4/4; score { part piano { voice right { | c4/4 d4/4 e4/4 f4/4 | g4/4 a4/4 b4/4 c5/4 d5/4 } } } }

Ties are one event

piece "tied" { tempo 1/4 = 72; meter 4/4; score { part violin { voice line { | a4/2 ~ a4/4 g4/4 | c5/1 } } } }
